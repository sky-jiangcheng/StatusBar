常见问题

如何刷新运行中的应用列表？
点击工具栏中的刷新按钮。StatusBar 也会按设置间隔自动更新列表。

为什么有些 Status Bar 应用无法打开？
macOS 不允许通过 NSRunningApplication.activate() 激活 accessory app（没有 Dock 图标）。StatusBar 改用 NSWorkspace.openApplication 唤起，个别 accessory 应用仍可能无法被其他 app 激活，这是系统限制。

StatusBar 是否收集个人数据？
不。运行中的应用信息在本地处理，不会上传到任何服务器。

需要 Accessibility 权限吗？
不需要。界面只读展示辅助功能开关状态，未开启不影响任何功能。

App Store 版和官网 DMG 有什么区别？
官网版（Developer ID）含退出 / 强制退出；Mac App Store 版受沙盒限制，这两项在编译期移除。两版 Bundle ID 不同，可同时安装。

Frequently asked questions

How do I refresh the list of running apps?
Tap the refresh button in the toolbar. StatusBar also refreshes on the interval you set.

Why can't some Status Bar apps be opened?
macOS does not allow NSRunningApplication.activate() on accessory apps (no Dock icon). StatusBar uses NSWorkspace.openApplication instead; some accessory apps still cannot be activated by another app. This is a system limitation.

Does StatusBar collect personal data?
No. Information about running apps is processed on your device and never uploaded.

Is Accessibility permission required?
No. The UI only displays the accessibility switch state; every feature works without it.

How does the App Store build differ from the DMG?
The Developer ID build includes Quit / Force Quit. The Mac App Store build strips those at compile time because of sandboxing. The two builds use different bundle IDs and can coexist.
