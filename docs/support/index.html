常见问题

如何刷新运行中的应用列表？
无需手动刷新：Topiary 按设置页的扫描间隔（1 / 2 / 5 秒）自动更新，列表与详情页会即时刷新。

为什么有些 Status Bar 应用无法打开？
macOS 不允许通过 NSRunningApplication.activate() 激活 accessory app（没有 Dock 图标）。Topiary 改用 NSWorkspace.openApplication 唤起，个别 accessory 应用仍可能无法被其他 app 激活，这是系统限制。

菜单栏图标被刘海挡住了？
Topiary 会自动检测并弹出管理窗口。首次使用建议 ⌘-拖动图标到顺手的位置，位置会跨启动保留；菜单栏过挤时也可退出部分 Status Bar 应用腾出空间。

如何唤起主窗口？
点击菜单栏图标打开弹窗，或按全局快捷键（默认 ⌃⌥M，可在设置页自定义或禁用）。

Topiary 是否收集个人数据？
不。运行中的应用信息在本地处理，不会上传到任何服务器。

需要 Accessibility 权限吗？
不需要。Topiary 只使用公共 API 列出运行中的应用，不涉及辅助功能框架。

App Store 版和官网 DMG 有什么区别？
官网版（Developer ID）含退出功能；Mac App Store 版受沙盒限制，该功能在编译期移除。两版 Bundle ID 不同，可同时安装。

Install

Frequently asked questions

How do I refresh the list of running apps?
There is nothing to refresh manually: Topiary rescans on the interval you set in Settings (1 / 2 / 5 s) and both the list and the detail pane update in place.

Why can't some Status Bar apps be opened?
macOS does not allow NSRunningApplication.activate() on accessory apps (no Dock icon). Topiary uses NSWorkspace.openApplication instead; some accessory apps still cannot be activated by another app. This is a system limitation.

My menu bar icon is hidden by the notch?
Topiary detects the occlusion and surfaces the manager window on its own. On first use, ⌘-drag the icon somewhere convenient — the position is remembered across launches. If the bar is genuinely full, quitting a few Status Bar apps frees it up.

How do I open the main window?
Click the menu bar icon to open the popover, or press the global hotkey (⌃⌥M by default; rebind or disable it in Settings).

Does Topiary collect personal data?
No. Information about running apps is processed on your device and never uploaded.

Is Accessibility permission required?
No. Topiary only uses public APIs to list running apps — the Accessibility framework is never touched.

How does the App Store build differ from the DMG?
The Developer ID build includes Quit. The Mac App Store build strips it at compile time because of sandboxing. The two builds use different bundle IDs and can coexist.
