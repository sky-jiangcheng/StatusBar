Topiary

macOS 菜单栏管理工具，自动检测并管理状态栏和 Dock 应用。

下载

从 GitHub Releases 下载最新 DMG （Developer ID 公证，含退出 / 强制退出）。Mac App Store 版另行分发。

功能特性

🔍 自动检测

基于 activationPolicy 自动区分 Status Bar 和 Dock 应用

⚡ 一键操作

打开、常驻、退出、强制退出应用

📌 状态栏常驻

勾选的应用图标直接入住系统菜单栏，始终可见、左键唤起、右键管理

🔎 搜索过滤

按名称或 Bundle ID 快速搜索

🎨 外观主题

跟随系统 / 浅色 / 深色，全局即时生效

🌍 多语言

简体中文 / English / 日本語 / Deutsch / Español

↕️ 拖拽排序

拖拽调整菜单栏图标的自定义顺序

🔒 无需权限

运行时不请求任何系统权限

App 类型

Status Bar 仅有状态栏图标，无 Dock 图标。使用 openApplication 激活。

Dock 有 Dock 图标。使用 activate 激活。

  • 框架：SwiftUI + AppKit
  • 架构：@Observable（Observation framework）
  • 构建：Swift Package Manager

系统要求

  • macOS 14.0+
  • 不请求任何权限：全部功能开箱即用，数据不出设备

Topiary

A macOS menu bar utility that automatically detects and manages status bar and Dock apps.

Download

Get the latest DMG from GitHub Releases (Developer ID notarized, includes Quit / Force Quit). The Mac App Store build is distributed separately.

Features

🔍 Auto detection

Classifies Status Bar vs. Dock apps using activationPolicy

⚡ One-click actions

Open, pin, quit, or force quit apps

📌 Resident menu bar icons

Pin apps to live directly in the macOS menu bar — always visible, one click to activate

🔎 Search & filter

Filter instantly by name or bundle identifier

🎨 Themes

System, light, and dark, applied instantly across the app

🌍 Languages

English, 简体中文, 日本語, Deutsch, Español

↕️ Drag to reorder

Arrange menu bar icons into a custom order

🔒 No permissions

Runs without requesting any system access

App types

Status Bar Status item only, no Dock icon. Activated with openApplication.

Dock Has a Dock icon. Activated with activate.

Tech stack

  • Language: Swift 6.0
  • Frameworks: SwiftUI + AppKit
  • Architecture: @Observable (Observation framework)
  • Build: Swift Package Manager

Requirements

  • macOS 14.0 or later
  • No permissions required — every feature works out of the box
