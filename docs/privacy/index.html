StatusBar 隐私政策

最后更新：2026年9月27日

StatusBar 不收集、存储、共享或出售任何个人数据。

数据收集

StatusBar 不收集分析数据、跟踪数据、账户信息、联系信息、位置数据或标识符。

本地设备信息

StatusBar 使用公共 macOS API（NSWorkspace.shared.runningApplications）列出本机正在运行的应用程序。这些信息只在设备上本地处理，不会传输到任何服务器。

权限

StatusBar 不请求辅助功能（Accessibility）权限，也不请求屏幕录制、输入监控、文件访问、网络访问或自动化权限。界面仅只读展示 AXIsProcessTrusted() 的结果，未授权不影响任何功能。

数据共享

由于 StatusBar 不收集个人数据，因此不与第三方共享个人数据。

StatusBar Privacy Policy

Last updated: September 27, 2026

StatusBar does not collect, store, share, or sell any personal data.

Data collection

StatusBar collects no analytics, tracking data, account information, contact information, location data, or identifiers.

On-device information

StatusBar uses public macOS APIs (NSWorkspace.shared.runningApplications) to list apps running on your Mac. This information is processed locally and is never transmitted to any server.

Permissions

StatusBar does not request Accessibility permission, nor screen recording, input monitoring, file access, network access, or automation. The UI only displays the result of AXIsProcessTrusted(); the app works fully without it.

Data sharing

Because StatusBar collects no personal data, no personal data is shared with third parties.
